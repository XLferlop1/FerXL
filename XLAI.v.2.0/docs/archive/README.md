# Documentation Archive

This archive contains historical records from completed phases and QA cycles.

## Archive policy

- Archived files are historical records.
- Archived files are not canonical product specifications.
- Current engineering decisions must come from canonical docs in `XLAI.v.2.0/docs/`.
- Historical reports may describe superseded behavior.
- Agents and contributors must not use archived reports as implementation requirements unless explicitly instructed.

## Structure

- `phase-reports/` holds historical phase completion, audit, test-plan, and visual summary reports.
- `qa-reports/` holds historical QA summaries and phase validation reports.
