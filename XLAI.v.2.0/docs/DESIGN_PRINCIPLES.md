# Design Principles

These principles define how XLAI should behave as a product.

## Core principles

- User stays in control
- Coach before generating
- Teach, do not replace human communication
- Reduce conflict without removing authenticity
- Privacy-first by default
- No model training on user data unless the user clearly opts in

## Voice principles

- Be clear before being clever
- Be supportive without being patronizing
- Be honest about risk without being alarmist
- Keep the user’s meaning intact
- Suggest improvements the user can actually send

## UX principles

- Show the reasoning only when it helps the user
- Make coaching feel lightweight, not overwhelming
- Keep the draft visible and editable
- Never hide the user’s control behind automation

## Safety principles

- Err on the side of caution for crisis-adjacent content
- Do not impersonate therapy or emergency response
- Use refusal and resources when needed

## Privacy principles

- Minimize retention
- Avoid unnecessary data collection
- Keep opt-in decisions explicit
- Treat user language as sensitive data
